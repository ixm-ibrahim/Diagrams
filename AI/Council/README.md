# ⚖ The Council

**Multi-perspective AI deliberation — run locally, no cloud required.**

The Council presents your question to a panel of AI advisors who debate it in sequence — each one reading what the others said before responding. A final Arbiter synthesizes their views. The result is richer, more honest analysis than any single AI response.

---

## How It Works

Each council session runs like this:

1. You enter a question
2. Selected members respond **in order**, each seeing prior responses
3. The **Arbiter** synthesizes the full deliberation
4. You get a complete "Council Report" you can copy as Markdown

The default panel:

| Member | Role | What they do |
|---|---|---|
| 🗡 The Skeptic | Devil's Advocate | Finds every flaw and risk |
| 🛡 The Champion | Steelman | Makes the strongest case *for* the idea |
| 🔬 The Reasoner | First Principles | Reasons from the ground up, ignoring convention |
| ⚙ The Pragmatist | Pragmatist | Cuts to what's actually actionable |
| ⚖ The Arbiter | Synthesis | Summarizes and gives concrete next steps |

## Prerequisites

- **Python 3.7+** — check with `python3 --version`
- **One of the following** for AI responses:
  - [Claude Code](https://claude.ai/code) installed and authenticated (`claude --version` should work)
  - An Anthropic API key from [console.anthropic.com](https://console.anthropic.com)

No other dependencies. The app uses Python's standard library only.

---

## Setup

```bash
# 1. Create the project folder
mkdir ~/council && cd ~/council

# 2. Place council.py here, then create the exports folder
mkdir exports

# 3. Verify Claude CLI is available (if using CLI mode)
claude --version
```

Your folder should look like this:

```
council/
├── council.py
├── README.md
├── exports/        ← paste your copied reports here
└── .gitignore      ← optional, if using git
```

---

## Running

```bash
python3 ~/council/council.py
```

The server starts on `http://localhost:8765` and opens in your browser automatically.

Stop it anytime with `Ctrl+C`.

## Usage

### Basic
1. Type your question in the text area
2. Toggle which council members should respond (minimum 2)
3. Click **Convene** — or press `Cmd+Enter` / `Ctrl+Enter`
4. Members respond one by one. The Arbiter always speaks last.
5. Click **📋 Copy Report** to copy the full session as Markdown

### Toolbar

| Icon | What it opens |
|---|---|
| 🕒 (top-left) | **History** — your last 15 sessions, click any to reload |
| ✎ (top-right) | **Member Editor** — customize the council |
| ⚙ (top-right) | **Settings** — switch between CLI and API key |

### Keyboard shortcuts

| Shortcut | Action |
|---|---|
| `Cmd/Ctrl + Enter` | Convene the council |
| `Escape` | Close any open panel |

## Connection Modes

The Council defaults to **Claude CLI** — no configuration needed if Claude Code is installed.

**CLI mode** (default):
- Uses your existing Claude Code authentication
- Each council member = one `claude -p` subprocess call
- No API key or billing setup required

**API key mode** (optional):
- Click ⚙ → paste your key from [console.anthropic.com](https://console.anthropic.com)
- Key is stored in your browser's localStorage (stays on your machine)
- Uses `claude-sonnet-4-5` directly via HTTPS
- A full 5-member session costs roughly $0.02–0.05

To switch back to CLI, open Settings and click **Clear key**.

## Customizing the Council

Click the ✎ icon to open the member editor. For each member you can change:

- **Icon** — any emoji or character
- **Name** — how they appear in the UI and exports
- **Label** — the role description shown in the header
- **Color** — accent color in the UI
- **System Prompt** — the actual instructions that shape their perspective

Click **+ Add Member** to create a custom advisor. Click **Reset Defaults** to restore the original four.

All changes are saved automatically to localStorage.

### Ideas for custom councils

- **Startup Council** — Investor, Customer, Competitor, Operator
- **Career Council** — Mentor, Recruiter, Devil's Advocate, Future Self
- **Creative Council** — Editor, Target Reader, Contrarian, Enthusiast
- **Life Decision Council** — Risk Manager, Optimist, Pragmatist, Values Advisor

## Exporting Reports

After a session, click **📋 Copy Report**. This copies a Markdown document to your clipboard:

```markdown
# Council Report

**Question:** Should I quit my job to start a company?
**Date:** 5/14/2026, 10:32:00 AM

---

## The Skeptic — Devil's Advocate

[response text]

---

## The Arbiter — Synthesis

[synthesis text]

---

*Generated by The Council*
```

Paste this anywhere — Obsidian, Notion, a text file, email. Works especially well as a permanent note in a second-brain system.

## Privacy

- All data stays on your machine
- Session history lives in your browser's localStorage
- If using CLI mode, no data leaves your computer except through Claude Code's normal authentication
- If using API key mode, prompts are sent to Anthropic's API over HTTPS (same as using claude.ai)
- Your API key is never sent to the local server — it's used directly by the browser

## Troubleshooting

**`claude` command not found**
Install Claude Code at [claude.ai/code](https://claude.ai/code), or add an API key in Settings instead.

**Port 8765 already in use**
Edit the `PORT = 8765` line near the top of `council.py` to any free port (e.g. `8766`).

**Responses are empty or cut off**
The default `max_tokens` is 1000. For longer responses, find `max_tokens: 1000` in the `askAPI` function and increase it. Note this raises cost per session slightly.

**Browser doesn't open automatically**
Navigate to `http://localhost:8765` manually.
