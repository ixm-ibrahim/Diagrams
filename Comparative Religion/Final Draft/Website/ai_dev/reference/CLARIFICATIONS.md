# Resolved Design Decisions

Closed questions whose answers bind ongoing audits. Reopen only if new evidence
forces it. Each one is an axiom: honor it, don't re-argue it.

These axioms are how the tree keeps specialist-grade precision after a
hard-to-adjudicate question has been worked through. Treating a settled answer as
"still open" during an audit trades hard-won precision for fresh speculation — and
the speculation is usually a downgrade, because the original decision was made with
more context than a per-node audit has. Where an axiom seems wrong, flag it
separately; don't override it mid-audit.

---

**Purpose = direction (1.2.5.1.2).** *"What is wanted."* No separate node. Cause
is grounded in will-body first; non-willful causation is separate.

**Sensation = intensity without wanting.** The *"without"* is an identity
distinction — a different quality *FROM* wanting (like *loud* ≠ *red*), NOT
"intensity when wanting is absent." Sensation and wanting can co-occur. Intensity
is a cross-cutting attribute of all phenomena; sensation is intensity *as its own
quality*.

**Correlation is strict.** A single observed break = no direct correlation. Will
is a *factor*, not the determining cause.

**Knowledge is defined without truth.** Knowledge = when an answer occurs. Can be
right or wrong. Knowledge is identifiable without truth; truth requires knowledge.

**Will is a specific type of want.** Will (1.2.5.1.8) = wanted want. Desire
(1.2.5.1.7) = unwanted want. *"I"* (1.3.7.1) is identified through will.

**"I want to know what is true" (1.7) is compatible with 1.6.** Wanting to know
truth = wanting knowledge, indifferent to which answer. Wanting a specific answer
to be true = different. 1.6 applies to the second.

**Truth corresponds with rationality, not comprehensibility.** All four
combinations of rational/irrational × comprehensible/incomprehensible exist.
Critical downstream for distinguishing mysteries vs. contradictions (Node 4).

**"Condition" grounds "if."** *If* introduces a condition → can't use *if* in
claims before 1.4.4.6.

**Necessary is prior to sufficient.** *"Removing breaks it"* (necessity) before
*"having guarantees it"* (sufficiency). Both before *"condition."*

**Possible/impossible are epistemic, not metaphysical.** *Possible* = no
contradiction with current knowledge. Can change after new learning.

**The 1.4 / 1.5 boundary.** 1.4 = structural (what logical things ARE). 1.5 =
process (what you DO with them). Test: static relationship = 1.4. Act, method, or
quality standard = 1.5.

**"Argument" is correctly non-willful.** The formal definition (premises +
conclusion) is purely structural. The willful act of constructing arguments lives
in 1.5's process terms.

**Three-layer distinction: implication / inference / mechanism.** Implication
(1.4.4.7) = static structural relationship. Inference (1.5.1) = observable event
of arriving at a new statement. Mechanism = *how* inference happens. Each
observable without the one above it.

**Logical "why" vs. causal "why."** Logical *why* = premises that imply truth
(justification, groundable in 1.4). Causal *why* = what produced an event
(requires non-willful causation).

**Justification belongs in 1.4.5, not 1.6.** A justification = valid argument
whose conclusion is a belief. A logical structure, not a process.

**Method belongs in 1.5.** A method = class of processes. *"Reasoning"* = a method
(the observe → identify → induce → deduce → verify pattern).

**Term-grounding = claims only.** Restrictions on capacity/causal/logical language
apply to node claims. Section content is explanatory prose — uses whatever
communicates clearly.

**All phenomena are qualities.** *Quality* (1.1.3) = any singular distinct
phenomenon. Everything after is a more specific kind of quality.

**Associations are a kind of quality** — the quality of connection. Not a separate
ontological category.

**Awareness is a quality** — the quality of occurrence. *"Red occurs"* =
*"awareness of red."* Not a separate layer on top of occurrence.
