# Specific Clarifications

Design decisions resolved during development. Each references the general
principle it instantiates, so similar future questions can be resolved the
same way.

---

## Resolved

**Purpose = direction (1.2.5.1.2).** "What is wanted." No separate node.
*Principle: convention 14 — don't create nodes for things already captured.*
Cause is grounded in will-body first; non-willful causation is separate.

**Sensation = intensity without wanting.** "Without wanting" = a different
quality FROM wanting (like loud ≠ red). They can co-occur. NOT "intensity
when wanting is absent." The "without" is an identity distinction. Intensity
is a cross-cutting attribute of all phenomena. Sensation is intensity as
its own quality. *Principle: types are children (7.1).*

**Correlation is strict.** A single observed break = no direct correlation.
Will is a *factor*, not the determining cause. *Principle: prefer weaker
observational claims (7.1).*

**Knowledge is defined without truth.** Knowledge = when an answer occurs.
Can be right or wrong. *Principle: break circularity (7.1). Knowledge is
identifiable without truth; truth requires knowledge.*

**Will is a specific type of want.** Will (1.2.5.1.8) = wanted want.
Desire (1.2.5.1.7) = unwanted want. "I" (1.3.7.1) is identified through
will. *Principle: types are children (7.1).*

**"I want to know what is true" (1.7) is compatible with 1.6.** Wanting to
know truth = wanting knowledge, indifferent to which answer. Wanting a
specific answer to be true = different. 1.6 applies to the second.
*Principle: terms match definitions, not connotations (7.5).*

**Truth corresponds with rationality, not comprehensibility.** All four
combinations of rational/irrational × comprehensible/incomprehensible exist.
Critical downstream (mysteries vs. contradictions in Node 4). *Principle:
two levels of visualization (7.3).*

**"Condition" grounds "if."** "If" introduces a condition → can't use "if"
in claims before 1.4.4.6. *Principle: extends 7.3 to all logical
connectives.*

**Necessary is prior to sufficient.** "Removing breaks it" (necessity)
before "having guarantees it" (sufficiency). Both before "condition."
*Principle: observe specific before naming general (7.1).*

**Possible/impossible are epistemic, not metaphysical.** "Possible" = no
contradiction with current knowledge. Can change after new learning.
*Principle: prefer weaker observational claims (7.1).*

**The 1.4/1.5 boundary.** 1.4 = structural (what logical things ARE). 1.5
= process (what you DO with them). Test: static relationship = 1.4. Act,
method, or quality standard = 1.5. *Principle: states before processes
(convention 5).*

**"Argument" is correctly non-willful.** The formal definition (premises +
conclusion) is purely structural. The willful act of constructing arguments
is captured by 1.5's process terms. *Principle: definitions match, not
connotations (7.5); states before processes (convention 5).*

**Three-layer distinction: implication / inference / mechanism.** Implication
(1.4.4.7) = static structural relationship. Inference (1.5.1) = observable
event of arriving at a new statement. Mechanism = how inference happens.
Each observable without the one above it. *Principle: occurrence ≠ mechanism
(7.3).*

**Logical "why" vs. causal "why."** Logical "why" = premises that imply
truth (justification, groundable in 1.4). Causal "why" = what produced an
event (requires non-willful causation). *Principle: states before processes
(5); occurrence ≠ mechanism (7.3).*

**Old 1.6 absorbed into new 1.6.** "Truth is independent from wanting"
follows trivially from 1.3.1 applied to truth. Used "make" (ungrounded).
Substantive content redistributed: hope/assumption cases → 1.6 observed
cases; wanting-to-know distinction → 1.7. *Principles: says anything new?
(7.5); avoid causal language (7.3).*

**Justification belongs in 1.4.5, not 1.6.** A justification = valid
argument whose conclusion is a belief. A logical structure, not a process.
*Principle: structurally belongs (7.5); states before processes (5).*

**Method belongs in 1.5.** A method = class of processes. "Reasoning" = a
method (the observe→identify→induce→deduce→verify pattern). *Principle:
don't sidestep definitions (7.4); structural placement (7.5).*

**Term-grounding = claims only.** Restrictions on capacity/causal/logical
language apply to node claims. Section content is explanatory prose — uses
whatever communicates clearly. *Principle: convention 9 — order of
identification, not language use.*

**All phenomena are qualities.** "Quality" (1.1.3) = any singular distinct
phenomenon. Everything after is a more specific kind of quality.
*Principle: types are children (7.1).*

**Associations are a kind of quality.** The quality of connection. Not a
separate ontological category. *Principle: types are children (7.1).*

**Awareness is a quality.** The quality of occurrence. "Red occurs" = 
"awareness of red." Not a separate layer on top of occurrence.

## Open / Tentative Deferrals

Concepts with unbuilt prerequisites. May land where noted or find a better
home.

- **Non-willful causation.** Extending cause beyond willful wanting.
  Requires projection, analogy, or model. Possibly Node 2.

- **Reason, why, explanation.** Both logical and causal senses need
  grounding together. Requires non-willful causation. Possibly Node 2.

- **Model, understanding, accuracy.** Model = internal representation.
  Understanding = model that matches reality. All require
  representation/analogy. Possibly Node 2.

- **Representation / Analogy.** One structure standing for another. Depends
  on structure (1.3.3), match (1.2.3), possibly abstraction (1.4.1.1).
  Possibly Node 2.

- **Projection.** Extending concepts from experience to observed patterns.
  Bridge between subjective and objective. Depends on analogy. Possibly
  Node 2.

- **Scope, resolution, context, meaning.** Full chain depends on
  model/representation. Possibly Node 2 or 3.

- **Certainty / Uncertainty.** Degree of confidence. Possibly Node 2 or 3.

- **Compulsion / Volition.** Three layers of wanting + probably "I."
  Possibly 1.3.7 children or later.

- **Verification → unobserved existence.** Derives + observes matching +
  independence → confirms unobserved thing's nature. Synthesizes 1.3 + 1.5.
  Possibly Node 2.

- **Logical system.** A model of statements. Meta-logical. Possibly Node 3.
