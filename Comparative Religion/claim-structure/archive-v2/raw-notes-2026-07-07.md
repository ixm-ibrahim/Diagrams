Phenomenological grounding (and the reason why I start here is it's the answer to avoiding circularity at all levels - like all claims must be grounded in something phenomenological as they are the ultimate givens, as they are non-claims themselves, therefore they fit the induction that all cycles must originate from something that isn't the thing itself, and that cycle ends/starts at this stage as phenomena make up of all things if that makes sense):

1. "phenomena occur"
2. "distinct phenomena occur" (ie. differences)
3. "qualities & associations occur (where associations are a type of quality)"
4. "will occurs (a type of quality)" & "temporal qualia occur (a type of quality - like 'before', 'after', 'time', etc.)" & "scope is a pattern that a set of observations have"
5. "correlation is a when a phenomena often follows another"
6. "independence is when phenomena do not correlate" & "necessity is when phenomena correlate without exception"
7. "ontological = whatever is not willed - or more accurately, independent of will (including will itself, as well as whatever is not directly observed)"
8. "causality = necessity, within the context of ontological events" (note that we already inferred that ontological events are caused by others, in which the cycle starts with an uncaused event [applying the same non-circular inference used everywhere else])
9. "intellectual causality = causality, within the context of imagination/thoughts" (applying the same observation here: intellectual events are caused by others [in which all the above are ontological, even your own will], in which the cycle starts with a non-intellectual event [ie. phenomenological primitive])
10. "truth = intellectual causality, within the context of undeniability" (note: again context matters, like the newtonian mechanics thing - the existence of special/general relativity doesn't mean that, within newtonian physics, time isn't absolute/constant... if you try to do relativity in newtonian physics, you get wrong answers)
11. "claim = a statement with a truth-value"
12. Some more, that should be ordered properly phenomenologically above, but I have them here so I don't clutter above:
    1. Statement - an inferential structure
    2. Event - an ontic structure
    3. Truth-value - where an inferential structure may or may not correspond with the ontic structure it refers to
        1. Truth is when it does correspond
        2. Falsehood is when it does not correspond
    4. Faithfulness - where a communicative structure may or may not correspond with the inferential/ontic structures it refers to
    5. Proof/justification - a sequence of claims in an inferential structure
    6. Conclusion - the final step of a proof
    7. Grounded - when a proof's first step is phenomenological
    8. Valid - when the link between a proof's conclusion and its previous steps occurs by intellectual causality
    9. Sound - when the every link in a proof occurs by intellectual causality

Claim structure:

- It basically broke it down into 7 pipelines: meaning (what does the claim say? output: what the claim is talking about, like what to imagine), scope/reference (what is the claim about, like what scope does the claim live under? output: the part of reality we're talking about), ontology (what has to happen in reality to make this claim occur? output: a fit with the known ontological conditions for the claim), proof (what justifies/points to the claim? output: the claim's external justification/proof, for anyone to observe for themselves), inferential (what allows the proof to lead to the claim? output: the claim's internal/logical justification/proof), truth (what makes the claim true? output: the claim's truth-value), and communication (how to faithfully communicate the claim? output: a proper, faithful understanding of the claim).

What each structure is made of:

1. Meaning: "claim (the 'what') <- cycle of (definition <- definition) <- phenomenological primitive" (where "definition" encompasses concepts, terms, etc. anything that references something specific)
2. Scope: "claim (its scope) <- cycle of (definition scope <- pattern identification <- ...) <- phenomenological primitives" (as a "scope", phenomenologically, is a pattern that joins/categorizes observations)
3. Ontological: "claim (its known ontological conditions) <- ontological event (that it references) <- cycle of (cause <- cause) <- intrinsic cause" (note that "cause" occurs within the scope defined earlier)
4. Proof: "claim (proof) <- cycle of (sign/support <- sign/support) <- phenomenological primitives" (note that I use "sign" here because signs "point to" a claim, and the actual logic is the rules of inference between them - ex. I feel wet, I ask "what points to that claim?" or "why should I believe that?", then I see that rain is occurring, and the droplets are corresponding to the feeling I get - and so some rule of inference allows me to go from seeing the rain to realizing that it's the reason for why I'm wet)
5. Inferential: "claim <- inferences <- cycle of (rule of inference <- rule of inference) <- logical/intellectual causality"
6. Truth: "claim (its truth-value) <- deniability (known ontological conditions) & (deniability [inferential proof] <- deniability [proof]) <- deniability (scope) <- deniability (meaning)" (basically applying deniability with all the previous outputs)
7. Communication: "claim (communication) <- demystification (word choice, selection, etc.) <- audience knowledge & audience disposition & audience language <- (human) psychological nature"?

Notes:

1. Deniability = whether or not denying it results in an inconsistency/knowing you're wrong? (not the ability to openly deny something or something like that, as explained earlier)
    1. As I anticipate misunderstanding here in which you will expose that "some truths are not undeniable to us" - so as an example, let's work through the claim, "There is microbial life somewhere outside Earth". By "undeniable", again I mean: based on what you know now, does this claim contradict anything when you deny it? (again, not a outward denial - I'm referring to the phenomenological occurrence of intellectual causality). And firstly, with unseen observations, you don't apply the "we only know if we see it" assumption here (this would be the hyperskeptical agnostic approach), rather we apply abductive reasoning (by some metric X, we will discover if we prefer A or B - where that metric X isn't necessarily "believing requires seeing"). So, if you know (for example) that knowledge of exoplanets and planets where we and directly see it occurs from statistics (from analyzing the atmosphere in other ways, or gravitational effect, etc. all secondhand relative to dropping a human or a probe to see it directly), then the scope of this whole thing is already not some of certainty but of probability. Within this, we know that laws of physics are universal everywhere, so we abductively apply the laws we know to any other potential planet. Then we look at our understanding of life and atmospheres, and vet the planet for its atmosphere to see if it fits. Etc. until we can't do anything anymore (statistically, as we already weren't directly observing it anyways). Then at the limits of our knowledge, we have to pick what approach best first the data that matters. So the whole thing reduces to using a statistical approach, not because the subject of undeniability doesn't apply: no we can apply that here, to the statistical level, the physics level, basically each scope layer, down to the claim itself.
    2. Then, falsehood = intellectual causality, within the context of deniability
2. Statement = a set of definitions + their associations
    1. Statements have comprehensibility (imaginable or not [regardless of observed context - like I can imagine "pink elephants" even though "elephants are not pink"]) - positive form is coherence, negative form is incoherence (like this is grounded within the limits of imagination, not the phenomena and laws you observed from reality)
    2. Statements have rationality (definitions are comprehensible or not [within their contexts - like a pink elephant is irrational because "elephants aren't pink"]) - positive form is rational, negative form is irrational (note that this is grounded in reality, like the "how" of whether or not definitions are comprehensible is based on the rules/context taken from the precedent of reality)
        1. Note: again I'm not saying that, as soon as you think something is rational or irrational, that you can't be wrong later - there is a step in the scientific method called "refinement", in which you update your beliefs based on new evidence (or evidence you hadn't considered properly before).
3. Along the way of discovering reality, we somehow discover the law of non-circularity: all cycles are observed to start from something that is not the thing (ex. chickens from a non-chicken, animals from a non-animal, life from non-life, planets from non-planets, universe from non-universe, etc.). This is in logic too: deductions from inductions, inductions from observations, observations from phenomena.
    - Btw, at no point do I insinuate that, once you learn something, it must be true - in terms of how you interpret it. Like if you see an apple, then you objectively saw an apple - that doesn't necessarily mean that you saw a "real" apple or not (see the above point about illusions vs. reality) - it's a categorization/interpretation problem.
4. The structure of a claim seems to say something about the truth of the claim itself (not to mention the claim's parts - and how the parts connect - are each a claim, by which they each have their own grounding in other claims and a structure, etc. - like there's possibly a self-referential component to a claim as well). Like for example: a lot of people think X confirms their beliefs, when X actually would confirm a false belief too - like a clock whose hands point to all times (it doesn't tell time - the right time - rather it points to all times, including both true and false times), or a smoke detector that beeps even when there's no smoke, etc. Perhaps this observation is just noticing that the "truth from the structure of a claim" is just its self-referential nature, or perhaps something more - idk.
    - It's not only truth vs. falsehood, but truth vs. truth mixed with falsehood… so the method/structure of the proof/justification for any claim can't be like a clock with hands that point to all sides (ie. something that also confirms falsehood, as if it's truth)
    - So somewhere along the way, there are conditions for the truth of a claim - one of which is the ability to distinguish between truth and falsehood (btw this is not saying that false outputs can't be caused by false inputs).
5. Reason (proof?): sequence of "intellectual causality" (ie. I don't decide if something results in truth or falsehood, I simply discover it)
    - Scientific Method: Observation -> Definition -> Induction -> Deduction -> Refinement
    - What that really means: Grounding in reality/established knowledge -> something identifiable with clear scope -> identify/observe (assume?) the pattern behind the defined scopes -> Apply observational precedent to patterns? and/or, observe what occurs after "intellectual causality" occurs? -> refine scopes from new information
6. The default/neutral position of people and AI nowadays seems to be an agnostic, physicsalist, hyperskepticalist view. This has a few problems:
    - This isn't actually a neutral position... there are rivals, and in absence of actual reasoning, this is, for some reason, seen as the "correct" view despite the valid existence of rivals.
    - And even if you dive deep into this "neutral default", you will find problems - such as the issue of the "hard problem". Those rival arguments' hard problem is seen as a fatal issue, when the "neutral" claim also has its own hard problems itself (what is the intrinsic nature of reality, what is causality, energy, dark energy, etc. anything fundamental, etc.) and the focus isn't shifted there, making it seem like the rival views are fundamentally flawed when that "flaw" is inherent here too.
        - And even then, hard problems don't disprove claims to begin with - especially hard problems about mechanisms - because physicalist/agnostic science doesn't and can't answer the intrinsic nature of things, it only sees effects to begin with, so hard problems will always exist. This wasn't the point of science to begin with - newtonian physics isn't "wrong" because relativity and quantum physics exist, rather it's true withing a "domain"/"context" - like it's only "wrong" if you make the assumption that it's the intrinsic nature of the world - the very same assumption this "default" can't make. (Btw: explaining the difference between metaphysical physicalism and methodical naturalism is even an example of this: metaphysical physicalism is obviously clearly a stance, while methodical naturalism sounds neutral - "when doing science, look for natural mechanisms" - but as soon as you ask "what does 'natural' mean [intrinsically]?" you expose that it usually means "what happens passively" - which is the same claim as metaphysical physicalism. Also note that I'm not automatically saying that physicalism in any form is right or wrong, all I'm pointing out that [using AI as the example], if I don't point this out, the AI will not say anything, as if it's working from a neutral base - but once I do, it will spend extra time explaining why I have to be careful in not dismissing the agnostic/hyperskeptic/physicalist view as a valid option, and to apply the same audit equally to the rivals and my own beliefs [which is true - I'm not saying that bias automatically makes something true or false] - which again makes it seem like the default should be that view)
        - Hard problems are just synonyms for limits of knowledge, showing that all knowledge requires context/domain to be meaningful. This directly addresses the hyperskeptical approach of "you can't know anything to be true", because we science starts from observations and builds models off of that - not from starting from some model and fitting observations to that, and then realizing later that no observations can expose the intrinsic nature that the "default" model you started with demands.
        - It's almost like, if you break it down enough, there seems to be an underlying assumption that "speculation can be used as proof/refutation" - when this inference is like a clock whose hands point in all directions, or a compass with a painted needle on it: it can't distinguish truth from falsehood.
            - This shows up often: like in topics in which abductive reasoning should be used, instead of identifying the metric by which a stance (among others) can be preferred, it uses the prior state of ignorance as an outcome of the abductive approach - as if that's the point of the exercise to begin with!
    - Another problem is like with the agnostic, hyperskeptical approach of illusions vs. reality - how do we know if anything is real? The problem with this framing is it starts with the model instead of observation.
        - We start with observing basic things - red, anger, 2, etc. - and call "reality" all that (ie. whatever we didn't will, what is independent of it). Then we discover different levels - like dreams and hallucinations - that doesn't mean that we suddenly discovered "non-reality"... those things are categorizations *within* reality. So "illusions" are "real" - there was never a contradiction - the issue was semantically drifting "real" between its universal meaning and its "not-dream"/"what everyone corroborates" meaning.
