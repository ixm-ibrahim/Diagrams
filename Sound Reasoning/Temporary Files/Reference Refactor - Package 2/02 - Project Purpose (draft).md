# 02 Project Purpose

What this project is doing, and why — the one page to read before any other.

## The whole idea

Every concept is built out of other concepts — "distinct" is said of things that occur, so it needs "occur" first. Follow any concept's parts down far enough and you hit blocks that are not built out of anything: concepts you get just by looking. Something occurs; things differ. This record exposes those blocks, one per node, in the order the concepts need each other — the block every other block needs comes first — and proves each one by looking, not by argument from another block. The links between nodes say one thing only: this block needs that block first. Truth comes from looking, at every node separately. Walk the links backward from any claim and you see every block it is made of, each proven by a look, nothing assumed. The effort is conceptual grounding — exposing the primitive building blocks of all concepts, in the order of their coverage, starting with the concepts that just appear; the section name "Phenomenological Primitives" already says it.
